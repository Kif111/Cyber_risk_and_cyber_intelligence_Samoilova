==================================================
СРО4. Поднятие веб-сайта через AWS
==================================================

ЦЕЛЬ РАБОТЫ:
Развернуть собственный HTML-сайт в облаке Amazon Web Services 
(на виртуальной машине EC2) и сделать его доступным в интернете.

ЧТО БЫЛО СДЕЛАНО:
1. В консоли AWS создана виртуальная машина (инстанс) на базе Ubuntu.
2. В настройках сети (Security Group) открыт порт 80 (HTTP), 
   чтобы к сайту был доступ из браузера.
3. На сервер AWS установлен Docker.
4. Образ с сайтом скачан из Docker Hub (kif111/my-website) 
   и успешно запущен на сервере.
5. Сайт доступен по публичному IP-адресу виртуальной машины.

ССЫЛКА НА DOCKER HUB:
https://hub.docker.com/r/kif111/my-website
