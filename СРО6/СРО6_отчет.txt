==================================================
СРО6. Оркестрация контейнеров (Docker Compose)
==================================================

ЦЕЛЬ РАБОТЫ:
Изучить инструмент Docker Compose и научиться запускать 
несколько контейнеров одновременно с помощью одного 
конфигурационного YAML-файла.

ЧТО ТАКОЕ DOCKER COMPOSE?
Docker Compose — это инструмент для определения и запуска 
многоконтейнерных приложений. Вместо того чтобы вручную 
запускать каждый контейнер командой docker run, вы описываете 
все сервисы в одном файле docker-compose.yml. Затем одной 
командой (docker compose up) поднимается вся инфраструктура.

ЧТО БЫЛО СДЕЛАНО:
1. Создано 5 независимых Docker-образов (сайт, SHA-3, 
   проверка паролей, сканер портов, Base64-кодировщик).
2. Написан файл docker-compose.yml, который связывает 
   все 5 контейнеров в единую систему.
3. Настроены порты и интерактивный режим (stdin_open, tty) 
   для программ, требующих ввода с клавиатуры.
4. Запуск всей системы выполнен командой: docker compose up -d
5. Проверено, что сайт доступен на порту 8080, а утилиты 
   запускаются через docker compose run <имя_сервиса>.
